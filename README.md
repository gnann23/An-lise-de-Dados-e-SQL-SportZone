# Análise de Dados e SQL Gerencial - SportZone

Projeto final desenvolvido para a disciplina de **Banco de Dados II** sob orientação do Prof. Lucas Misael.

## 📌 Sobre o Projeto
O objetivo do projeto foi transformar dados brutos de um banco MySQL relacional (`sportzone`) em relatórios gerenciais e KPIs acionáveis para tomadas de decisão nas áreas de Marketing, Vendas, Estoque e Diretoria.

## Principais Insights do Negócio
- **Concentração de Receita:** 69,08% do faturamento está concentrado em apenas 5 clientes (Curva de Pareto).
- **Inatividade:** 25% da base de clientes cadastrados ainda não realizou compras.
- **Eficiência de Estoque:** Mapeamento de capital imobilizado com itens de baixo giro.
- **Vendedor Destaque:** 28% de todas as vendas concentradas em um único vendedor.

## 🛠️ Recursos SQL Utilizados
- CTE (`WITH`)
- Agregadores e Agrupamentos (`SUM`, `COUNT DISTINCT`, `AVG`, `GROUP BY`, `HAVING`)
- Junções (`INNER JOIN`, `LEFT JOIN`, `UNION`)
- Subconsultas correlacionadas (`NOT EXISTS`)
